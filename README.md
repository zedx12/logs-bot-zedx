# Discord Logging Bot

بوت ديسكورد للتسجيل ومراقبة النشاطات في السيرفر

## المميزات

- تسجيل حذف وتعديل الرسائل
- تسجيل دخول وخروج الأعضاء
- تسجيل نشاطات القنوات الصوتية
- أوامر لعرض معلومات القنوات والسيرفر
- إمكانية تغيير قناة السجلات

## متطلبات التشغيل

- Python 3.8 أو أحدث
- حساب Discord Developer
- توكن البوت
- معرف قناة السجلات

## التثبيت

1. قم بتثبيت المتطلبات:
```bash
pip install -r requirements.txt
```

2. قم بإنشاء ملف `.env` وأضف المتغيرات التالية:
```env
TOKEN=your_bot_token_here
LOG_CHANNEL_ID=your_log_channel_id
```

3. قم بتشغيل البوت:
```bash
python bot.py
```

## نشر المشروع على Railway

1. قم بربط حسابك على GitHub مع Railway
2. قم بإنشاء مشروع جديد واختر المستودع
3. أضف المتغيرات البيئية (`TOKEN` و `LOG_CHANNEL_ID`) في إعدادات المشروع
4. سيتم نشر المشروع تلقائياً

## الأوامر المتاحة

- `/channel-info` - عرض معلومات القناة الحالية
- `/server-stats` - عرض إحصائيات السيرفر
- `/set-log-channel` - تعيين قناة السجلات (للمشرفين فقط)
